# Week 1: Frontend UI & Onboarding Design

## 🎯 Objectives
- Build responsive React 19 UI with Thapar Institute crimson/amber theme.
- Create multi-step student and faculty onboarding views.

---

## 🛠️ Key Implementation Details

1. **Student Onboarding**:
   - Captured Full Name, 10-digit Roll Number, Branch, Batch group (`3Q11`–`3Q15`), and Year of Study.
2. **Faculty Onboarding**:
   - Captured Department, Designation, and multi-course registration.
